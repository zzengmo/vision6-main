SteelVision ML — 철강 표면 결함 분석 웹

[00:00] 철강 품질, 새로운 시선
철강 표면의 작은 차이, 실제 데이터로 확인합니다.
SteelVision ML은 이미지 분석과 품질 검수를 연결한 웹입니다.

[00:12] 하나로 연결된 검수 과정
영상 메인에서 여섯 가지 기능으로 이동합니다.
데이터 탐색부터 품질 판정, 결함 위치와 결과 저장까지 연결했습니다.

[00:24] 데이터와 원본 확인
실제 저장된 데이터 통계와 클래스 분포를 확인합니다.
제공된 원본 사진을 정답 마스크 예시와 함께 살펴봅니다.
빨간 정답 영역은 모델 예측과 구분해 표시했습니다.

[00:39] 원본과 전처리 결과 비교
이미지를 올리고 전처리 옵션을 선택합니다.
원본과 처리 결과, 밝기 히스토그램과 에지 밀도를 확인합니다.
체험 옵션은 모델의 실제 추론 전처리를 변경하지 않습니다.

[00:57] 정상 이미지 품질 검수
자동 품질 검수에서 모델과 판정 기준을 선택합니다.
정상 예시를 올리고 검수 실행을 누릅니다.
실제 모델의 이미지 단위 판정과 점수, 처리 시간을 확인합니다.

[01:15] 불량 판정과 결과 저장
이번에는 불량 예시로 바꾸어 다시 검사합니다.
이미지가 바뀌면 이전 결과가 지워져, 서로 다른 검사 결과가 섞이지 않습니다.
판정은 CSV로, 검사 원본은 PNG로 내려받습니다.

[01:35] 실제 예측 마스크와 결함 위치
결함 위치는 별도의 U-Net 모델로 분석합니다.
원본 이미지와 실제 예측 마스크, 위치 박스를 나란히 확인합니다.
좌표는 원본 기준이며, 마스크와 좌표 파일도 내려받을 수 있습니다.
품질 판정과 위치 분석은 서로 다른 모델의 결과입니다.

[02:03] 평가의 출처와 단위 구분
현재 PC의 평가와 노트북에 저장된 결과를 구분해 보여줍니다.
이미지 분류 지표와 픽셀 단위 분할 지표도 각각의 의미로 확인합니다.

[02:16] 화면 크기에 맞춘 작업 공간
모바일에서도 같은 기능을 사용할 수 있습니다.
상단 탭과 전체 메뉴로 화면을 이동합니다.

[02:24] 작은 차이를 발견하는 기술
작은 차이를 발견하고, 실제 결과로 판단합니다.
